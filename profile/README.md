# 7runs

**Run your AI agent seven times. See how often it changes its answer.**

7runs is an open-source CLI for testing and evaluating AI agents: golden YAML suites, 7 repetitions per case, pass rates with Wilson 95% confidence intervals, first-class flakiness, double-judged LLM checks, and regression gates for CI. No telemetry, and API keys never touch disk. Works with your Claude Code subscription — no API key required.
